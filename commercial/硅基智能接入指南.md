# 硅基智能数字人 API 接入指南（无需 GPU，微信充值）

> 目标：让 `batch.py` 自动生成**真人脸 + 对口型**的数字人视频，
> 全程云端，你电脑不用显卡。约 0.3 元/分钟。

---

## 第一步：注册 + 充值（10分钟）

1. 打开 **https://www.guiji.ai**（硅基智能官网），微信扫码注册
2. 进控制台 → 实名认证（企业/个人都行）
3. 充值：支持微信/支付宝，先充 50 元够测试很多条

---

## 第二步：拿 API Key

1. 控制台 → 「**开发者**」/「**API 管理**」
2. 创建应用 → 复制 **API Key**（形如 `sk-xxxxx`）
3. 这个 Key 填到租户配置的 `digital_human.api_key`

---

## 第三步：选数字人形象，记下 avatar_id

1. 控制台 → 「**数字人形象**」
2. 选一个免费的商务/带货形象（想用刘老板自己的脸需要「形象定制」，
   那是付费录制，先用现成的跑起来）
3. 点进形象详情，复制 **形象 ID / avatar_id**
4. 填到租户配置的 `digital_human.avatar_id`

---

## 第四步：改配置，跑起来

编辑 `commercial/tenants/factory_a/config.yaml`：

```yaml
digital_human:
  backend: guiji              # 从 mock 改成 guiji
  api_key: "sk-你的硅基key"
  avatar_id: "你复制的形象ID"
```

跑：

```bash
python batch.py --tenant factory_a \
    --script commercial/tenants/factory_a/scripts/01_毛巾首条.txt
```

流程会自动：
仿写稿/现成脚本 → （声音克隆，可选）→ 字幕动画 → **硅基云端生成数字人脸+口型**
→ 数字人小窗叠加到字幕背景 → 成品 mp4。

成品在 `commercial/tenants/factory_a/out/final_*.mp4`。

---

## 注意事项

- **接口字段以官方文档为准**：`digital_human.py` 里 `GuijiBackend` 的
  上传/创建/查询接口路径（`/v1/upload`、`/v1/video/create`）是按通用 REST
  约定写的，如果硅基官方文档字段名不同，照着文档改 `GuijiBackend` 那几行即可，
  其它流程不用动。
- 第一次先用 1 条短脚本测试，确认扣费和成品没问题再批量。
- 声音克隆要客户本人授权；不克隆就用硅基自带音色，照样能发。

---

## 出问题怎么排查

```bash
# 单独测数字人这一步（不跑整条流水线）
python 04-digital-human/digital_human.py \
    --backend guiji \
    --audio commercial/tenants/factory_a/out/voice_xxx.wav \
    --out /tmp/test_dh.mp4
```

报错通常是：key 没填对 / avatar_id 错 / 余额不足 / 接口字段对不上文档。
